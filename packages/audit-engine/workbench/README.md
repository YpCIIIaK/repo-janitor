# auditscout workbench

Локальный стол для охоты: проекты, HP-программы, аудиты, чужие disclosed, свои LEAD.
SQLite в `workbench/data/workbench.db`. Ничего не уходит в сеть, кроме ссылок, которые ты сам открываешь.

## Запуск

```powershell
cd D:\auditscout\workbench
npm install
npm run dev
```

Открой http://localhost:3333

На дашборде нажми **Индексировать диск** — подтянет `data/bounty/*`, HP JSON, тексты аудитов, METHOD/NEXT.

## Стек

- Next.js 15 (App Router) + React 19
- SQLite через встроенный `node:sqlite` (Node 22+) — без native-модулей
- FTS5 поиск

## Рынок и мишени (16.08.2026)

**Рынок баунти** (`/market`) — 552 программы с шести площадок: cantina,
immunefi, hackenproof, standoff365, yeswehack, sherlock. Фильтры по площадке,
«только контракты», «с GitHub», «без комиссии и KYC». Чекбоксы → **В мишени**,
площадки можно мешать в одном выборе.

Сверху `/market` — два графика и два списка свежего: программы по площадкам
(с потолком и числом контрактных), теснота против потолка (точки только там,
где площадка публикует число заявок — у immunefi, hackerone, bugcrowd и
intigriti его нет, и рисовать их нулём было бы ложью), «новые с прошлого
снимка» (из `market_prev.json`) и «обновлены за 30 дней». У каждого графика
есть переключатель в таблицу.

**Мишени** (`/targets`) — выбранное, с кнопками **Подготовить** (скоуп, адреса,
скачанные исходники в `data/bounty/<slug>/`) и **Сканировать** (пять сигналов в
`signals/*.txt`). Обе кнопки запускают тот же `targets.py`, что и консоль, и
обе идут минутами: вывод течёт в `ui-prep.log` / `ui-scan.log`, страница
показывает хвост и сама обновляет состояние по завершении.

**Два хранилища, и это намеренно.** Рынок и мишени живут в файлах
(`market.json`, `targets.json`), а старый конвейер скана — в SQLite
(`programs`, `jobs`, `reports`). На `/stats` они показаны двумя строками и
не складываются: `programs` это импорт каталога HackenProof, он же часть
рынка, и общая сумма была бы двойным счётом.

Общий с CLI не только код, но и файлы: `../data/market.json` и
`../data/targets.json`. UI и консоль всегда видят одно и то же, поэтому можно
выбрать мышкой, а работать в терминале, и наоборот.

Снимок рынка обновляется командой `python market.py --refresh`.
Интерпретатор берётся из `AUDITSCOUT_PYTHON`, иначе Python313 из LOCALAPPDATA.
