# Площадки: что открыто машинно и что с доступом из Казахстана

Проверено 16 августа 2026 запросами из этого проекта. Колонка «в market.py»
означает, что список программ тянется автоматически и без ключа.

| площадка | программ | что отдаёт | доступ |
|---|---|---|---|
| immunefi | 186 | **весь скоуп**, потолки, KYC | регистрация свободная, выплаты в крипте |
| hackerone | 449 | имя, дескриптор, решённые отчёты | свободная; наград и скоупа в API нет |
| bugcrowd | 250 | вилка наград, отрасль, `accessStatus` | свободная; часть программ по инвайту |

| intigriti | 160 | вилка наград в евро, отрасль | свободная |
| hackenproof | 126 | заявки, теги, **скоуп** | свободная |

| sherlock | 4 | строки Public Bug Bounty | свободная |

Технические ходы, которые пришлось найти:

* **HackerOne** — `hackerone.com/programs/search?query=type:hackerone`. Заголовок
  `Accept` обязан быть РОВНО `application/json`: с обычным
  `application/json, text/plain, */*` отвечает 406. Ни наград, ни активов в
  выдаче нет, `policy_scopes` и `graphql` без сессии — 404. Плотность по H1
  не считается вовсе.
* **Bugcrowd** — открыт `engagements.json?category=bug_bounty`, по 24 на
  страницу. Это `programs.json` отвечает 404 и однажды увёл нас в вывод
  «Bugcrowd закрыт».
* **Intigriti** — открыт НЕ `api.intigriti.com` (401/404), а
  `app.intigriti.com/api/core/public/programs`. Поле `status`: 3 — приём
  открыт, 4 — закрыт.
* **Immunefi** — `immunefi.com/public-api/bounties.json`, шесть мегабайт со
  всем скоупом.

## Не подключено, и почему

| площадка | причина |
|---|---|
| Open Bug Bounty | API за Cloudflare (403). И платят там не деньгами, а признанием: для практики годится, для заработка нет |
| Vulnerability Lab | не площадка, а статический СПИСОК чужих программ; своей выдачи нет |
| Cobalt | это PTaaS: не баунти, а пентесты по контракту. В Cobalt Core берут по заявке и собеседованию, программ в открытом виде нет |
| Detectify | продукт для компаний; Crowdsource — закрытая сеть по приглашению |
| Inspectiv | только приватные программы, доступ по приглашению |
| Federacy | то же: приватные программы, публичного каталога нет |
| Hats Finance | домен API не отвечает |

Смотреть их руками имеет смысл только у Cobalt (подать заявку в Core) и Open
Bug Bounty (потренироваться без денег).

## Доступ из Казахстана

**Ограничений по гражданству нигде не нашлось.** Ограничения на этих
площадках устроены одинаково: запрещены резиденты стран под экспортными
санкциями США — Куба, Иран, КНДР, Сирия, Крым и подобное. Казахстана в этих
списках нет, поэтому участие и выплаты на HackerOne, Bugcrowd, Intigriti,
Immunefi, YesWeHack, Cantina, HackenProof доступны.

Что ДЕЙСТВИТЕЛЬНО может упереться — не право участвовать, а рельсы выплаты:

* **HackerOne** платит банковским переводом (30 валют, почти любая страна),
  через PayPal или напрямую в кошелёк (BTC/USDC). Банковский перевод и крипта
  из Казахстана работают; PayPal в РК на приём денег исторически ограничен —
  на него не закладываться;
* **Immunefi, Cantina, Sherlock** — крипта в кошелёк, вопрос страны не
  возникает вовсе. Это самый простой путь;
* **Bugcrowd, Intigriti, YesWeHack** — банк или PayPal; проверить свой
  вариант в кабинете ДО первой заявки;
* **Standoff 365** — российская площадка, награды в рублях. Условия выплаты
  нерезиденту РФ по открытым страницам проверить не удалось (соглашение
  отдаётся только внутри кабинета). **Это единственная площадка из девяти,
  где перед работой надо выяснить вопрос выплаты, а не после.**

Отдельно про KYC: он не про страну, а про программу. В снимке это видно
колонкой «комис.» — `KYC` означает, что личность придётся раскрыть перед
выплатой.

Полезное следствие для нас: девять площадок из девяти открыты, а самый
дешёвый по трению путь — те, где платят криптой и нет комиссии за подачу
(Immunefi, Cantina без комиссии, Sherlock).

у остальных список программ живёт за логином, и это проверено запросами,
а не предположено.

| Площадка | Регион | Машинно | Что нашли |
|---|---|---|---|
| **BI.ZONE Bug Bounty** | Россия | **да, подключена** | `bugbounty.bi.zone` |
| BugBounty.ru | Россия | нет | `bugbounty.ru` |
| TumarOne | Казахстан | нет | `tumar.one` |
| Uzhunter | Узбекистан | нет | `uzhunter.com` |
| Hacktify | Венгрия / ЦВЕ | нет | `hacktify.eu` |

### BI.ZONE — подключена

Единственная площадка СНГ, где скоуп открыт без логина, и притом целиком.
Две ручки DRF, обе публичные, `limit` режется сервером до 100:

- `/api/bug-bounty/companies/` — 81 компания (это и есть «программа»);
- `/api/bug-bounty/tasks/` — 382 задачи (это и есть «активы»).

Склеиваем по `task.company.id`. Отбрасываем `inArchive`, `inScope: false`,
непубличные компании и компании без единой живой задачи. Осталось 68 программ.

Важное про выплаты: максимума они **не публикуют вообще** — только `sumRewards`
и `avgRewards` по уже выплаченному. Ставить среднее в поле «максимум» нельзя,
оно уедет в график «приз против тесноты» и соврёт там. Поэтому `reward = 0`
(неизвестно), зато `reports` и `assets` открыты оба, и плотность считается
честно — редкость даже среди крупных площадок.

Скоуп у них — веб и госсистемы, смарт-контрактов нет. В контрактной выдаче
их не видно, нужен `--all`.

### Остальные четыре — за логином

Проверено запросами, повторять не нужно:

- **BugBounty.ru** — Next.js, список под `/app/programs` отдаёт 530 байт
  оболочки SPA; данные тянутся после входа.
- **TumarOne** — фронтенд Next.js, бэкенд на Go (`404 page not found` текстом).
  Страница `/programs` серверно пуста, во всех 22 чанках есть только маршрут
  `/programs/${id}`, ни одного `/api/`-пути. Значит, запрос идёт из серверного
  компонента на внутренний хост, наружу его нет.
- **Uzhunter** — Laravel + Vite. Наружу только `/login`, `/register`,
  `/leaderboard`, `/contact`. Страницы со списком программ нет вовсе.
- **Hacktify** — обычный сайт на WordPress (Elementor, BetterDocs).
  `wp-json` открыт, но среди типов записей программ нет: это витрина,
  само приложение живёт отдельно.

Что это значит: перечисленные четыре имеют смысл как ручная закладка, но
в снимок рынка их не поставить, пока не появится вход по сессии. Заводить
ради них авторизацию сейчас нечестно по цене — 0 контрактных программ
на четырёх площадках.
