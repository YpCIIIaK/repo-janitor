# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through
[GitHub security advisories](https://github.com/YpCIIIaK/repo-janitor/security/advisories/new).

Include the affected component (dashboard, CLI, GitHub Action or core scanners), a reproduction and the impact you see. You should get a reply within 7 days.

## Supported versions

Only the latest release and `main` receive fixes.

## Scope

In scope: the hosted dashboard, the `repo-janitor` CLI, the GitHub Action and the scanner packages in this repository.

Findings that repo-janitor reports *about other repositories* are not vulnerabilities in repo-janitor; report those to the affected project.
