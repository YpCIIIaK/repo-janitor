## Network integrity repair

The environment's outgoing HTTP proxy repeatedly returned HTTP 503 for GitHub, OSV and npm. Failed clones and metadata queries must not be counted as successful scans. In particular, the CLI can swallow an OSV transport failure and return no advisory findings. The benchmark collector now rejects incomplete metadata responses, retries, and caches only atomic, successful results. Core scanner behavior remains unchanged.

`benchmark/network-audit.mjs` observes the existing transport without changing proxy, TLS, DNS guards or query content. Audit output stores counts and safe service names, not credentials, package lists or request bodies. Existing response-size limits are recorded separately; successful transport is not a claim of unlimited advisory coverage.

A regression test reproduced the former false-clean cache behavior and failed before the collector repair. All 42 benchmark helper tests pass after the repair. 335 online results from the affected interval were quarantined and are being rechecked. Older cached data is retained: the progress file explicitly distinguishes audited from legacy online results.
