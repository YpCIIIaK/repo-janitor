# 2026-11-08: TODO source audit and generated informer false positives

## Change

Ignore TODO markers only in Go files carrying the canonical `// Code generated ... DO NOT EDIT.` line before the package declaration. A generated filename alone, a similar noncanonical comment, or the same header after the package declaration does not suppress findings. The exclusion recognizes a generated-output contract rather than a directory convention. License preambles and CRLF are supported.

Three source-reviewed findings across three repositories have the identical upstream informer-gen TODO copied into files explicitly marked DO NOT EDIT. These TODOs belong to the generator template; downstream maintainers should not patch generated copies.
