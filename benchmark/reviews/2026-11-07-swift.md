## Added rule families and validation

- `swift-tls-validation-disabled`: executable construction of DisabledTrustEvaluator or legacy ServerTrustPolicy.disableEvaluation; negatives include default/pinned evaluators, comments and string examples. Commit `55fb18b`.
- `swift-plaintext-credential-storage`: UserDefaults.standard set/setValue with exact credential key and raw credential value/literal; ignores ordinary preferences, nil/removal, booleans, encrypted transformations, Keychain writes. Commit `c58de01`.
- `swift-ecb-encryption`: CCCrypt options argument explicitly contains kCCOptionECBMode; ignores CBC options, AES.GCM, comments and string mentions. Commit `9f970d2`.

## Scope and open work

Local single-line static matching remains intentionally bounded. Swift files containing raw/multiline strings are skipped; multi-line call arguments and cross-function dataflow are unsupported. No broad command-injection rule added without evidence that Swift Process reaches a shell (`Process.arguments` with separate arguments is ordinarily safe). Security families for stored secrets, explicit TLS bypass and ECB do not require request taint; these are API configurations with direct security meaning.

## Real SQL recall correction

Pinned iGoat `SQLInjectionExerciseVC.swift` declares `searchField: UITextField`, conditionally assigns a search string, then interpolates SQL outside the conditional. Initial implementation missed this because names were heuristic and every `}` cleared taint. Scanner now recognizes declared UITextField/UITextView/UISearchBar variables and tracks nested declaration scopes: conditional assignments to outer variables survive, block-local declarations expire, function exits clear taint, typed class properties survive method exits. Direct scanner validation now yields one high-taint SQL hit at `sqlite3_prepare_v2`, line 22. Independent representative regression and safe UILabel/scope negatives added. All 19 Swift tests and core tsc pass.
