### Reference databases

`benchmark/SECURITY-SOURCES.md` assesses CodeQL, CWE, OWASP, Semgrep, MobSF and NIST/Juliet sources and licenses. CodeQL's MIT query repository is the primary reference; external rule packs were not blindly vendored or translated. `security-models.json` records source/sink/safe-case contracts.

`benchmark/owasp-score.mjs` reads an external OWASP BenchmarkJava checkout and expectedresults CSV, matches case/CWE findings, distinguishes unsupported categories and excluded paths, verifies commit provenance, and warns about scanner caps. It never creates labels automatically. Nine independent adapter tests pass.

The old path filter excluded the OWASP Java package entirely. The corrected scanner reaches it. At the pinned SHA, the capped run yields 38 TP / 20 FP across supported cases with all findings, or 22 TP / 8 FP with default-visible findings. **This is not a full recall estimate:** the 60-finding scanner cap was reached, so absent findings/FN/TN do not prove complete analysis. Exact results and caveats are in the two OWASP evaluation JSON files in `benchmark/reviews/`.
