### На другой машине — предпочтительный локальный вариант

Нужны Claude Code с терминалом, Node.js 22+, pnpm, Git и tar. Используй новый
checkout, чтобы не перекрыть чужие данные или ранее установленный baseline.
Команды подходят для PowerShell/macOS/Linux:

```sh
git clone --depth 1 --single-branch --branch bench/2026-11-16-1 https://github.com/YpCIIIaK/repo-janitor.git repo-janitor-resume
cd repo-janitor-resume
pnpm install --frozen-lockfile
pnpm run build:packages
node --input-type=module -e "import {scanFingerprint} from './benchmark/fingerprint.mjs'; console.log(scanFingerprint())"
pnpm local:rescan restore 13806709c1a080cd844a5400a667152ca1ada029
pnpm local:dashboard
```

Отпечаток должен быть `55fde0549e7b2b7d`. Если отличается, выясни причину
до продолжения; не подменяй отпечатки в данных. Для точного переноса с Linux
на Windows может понадобиться WSL: пути участвуют в существующем fingerprint.
Нельзя обещать повторное использование готовых записей при другом отпечатке.

`restore` проверяет SHA-256 и сохраняет данные отдельно в
`benchmark/.local-rescans/baseline/`. В дашборде `/local-rescan` выбери весь
корпус, **«Только изменившиеся сканеры»**, нужное число процессов (по умолчанию
4) и исходный опубликованный/baseline-набор. Запуск использует checkpoint,
пропускает актуальные проверки и пишет новые результаты в отдельный workspace.
Не используй здесь старый ref по умолчанию: для этой паузы нужен именно
`bench-data-2026-11-16-1-checkpoint`.

Без браузера создай `claude-resume.json`:

```json
{
  "mode": "changed",
  "jobs": 4,
  "minFreeGiB": 2,
  "timeoutMinutes": 30,
  "refreshMetadata": false
}
```

```sh
pnpm local:rescan run claude-resume.json
```

Старые онлайн-снимки сохранены. Обновление OSV/лицензий — отдельный этап,
а не следствие завершения офлайн-задачи. После завершения локального запуска:
`pnpm local:rescan export UUID`. Сохрани архив и SHA-256 для дальнейшей проверки.

## Implemented

| Change | Regression evidence |
|---|---|
| Java SQL: distinguish strings passed directly to log/exception APIs from query construction | Failing-before regression; nested DB calls and adjacent statements retained; four reviewed FP reproduced and removed |
| Commented code: prose contracts, trigonometric identities and polynomial derivations | Failing-before regression; disabled statements and pointer writes retained; three reviewed FP reproduced and removed |
| Docker socket: a read-only mount does not disable mutating Docker API calls | Failing-before short/long mount regression; corrected remediation; existing intentional Docker infrastructure exceptions retained |
| PHP flow: quoted control-flow words no longer kill request provenance | Failing-before path-read, XXE and Twig cases; actual control-flow/function boundaries retained |
| `/stats` → `/state`: mixed-language file footprint and metadata completeness | Pin-mismatch, alias and provider-limit tests; production build and HTTP smoke passed |

Public statistics distinguish 10,000 GitHub projects from 10,007 pinned records
and seven alias records. The technology table counts file presence across
inventories, including secondary languages and generated/vendor code. It does
**not** claim those files were all analysed or that language security coverage
is equivalent. PHP and Swift detectors exist in this branch; a dedicated Erlang
detector is not integrated here.

The new public metadata counts distinguish successful transport audits, older
snapshots without that audit, response-size limitations, and lookup dates.
They do not expose private usage records or change authentication on `/api/stats`.

The `/state` follow-up also exposes the already-computed raw and size-adjusted
practice score gaps, finding-density gaps and practice sample counts. It explains
the four size bands and the difference between association and causation.
Reviewed TP/FP numerators and the precision formula accompany the confidence
chart. `/state/data.json` downloads the same public aggregate snapshot for
independent analysis; it contains no private usage events or scan submissions.
