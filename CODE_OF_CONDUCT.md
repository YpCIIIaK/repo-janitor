# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give constructive feedback, and keep discussion about the work. Harassment, personal attacks and publishing others' private information are not tolerated.

Report unacceptable behaviour privately through [GitHub security advisories](https://github.com/YpCIIIaK/repo-janitor/security/advisories/new) or to the repository owner. Reports are handled confidentially, and maintainers may remove contributions or block participants who violate this code.
