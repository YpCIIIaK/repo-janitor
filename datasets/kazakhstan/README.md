# Kazakhstan-related repository research

The [2026-11-12 snapshot](2026-11-12/README.md) contains 635 unique public repositories and 13,867 automatic scanner signals. Every repository in that queue has been processed; four have no Git refs and therefore no source revision to scan.

This is a discovery and static-analysis dataset. A company-name match, an employee's personal project, or a parent company's account does not prove ownership by a particular Kazakhstan legal entity or production use. Forks, archived repositories, examples, research, and hiring exercises remain in the inventory and must not be treated as independent commercial products.
